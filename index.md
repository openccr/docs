# Rebus Protocol Documentation

Rebus is the openCCR inter-board CAN-bus protocol. This site publishes the Rebus protocol reference; the repository's BLE documents are outside this site's scope.

## Choose a starting point

- [Understand the Rebus document map](rebus/README.md) — scope, protocol owners, and a reading order.
- [Implement the protocol](rebus/AGENTS.md) — task-specific read sets and ownership boundaries.
