# Rebus issues in specified functionality

This ledger records defects or documentation-conformance failures in rules that
have already been stated. It does not assign missing wire values or supply
replacement normative rules. Unspecified contracts, including details needed
by an otherwise specified flow, belong in [missing functionality](missing-functionality.md).
The original source headers are unavailable here, so this is an internal
consistency audit, not a firmware-conformance claim.
